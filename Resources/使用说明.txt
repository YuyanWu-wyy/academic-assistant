学术助手 · DeepSeek（1.5.0）

用途
在 Overleaf 或浏览器 PDF 中选中文字，通过快捷键在本机窗口里润色、解释或翻译。程序直接连接 DeepSeek API，不依赖 DeepSeek Harness。

论文索引：找回以前读过的论文
点击“论文索引”，可搜索标题、主题标签和摘要关键词。已有完整论文阅读记录会自动收录；以后通过助手导入或打开论文、更新导读，也会同步卡片。
卡片仅保存标题、链接、标签、最多 600 字符摘要及用于关联和排序的标识与时间，不保存 PDF、全文、笔记或问答副本。原有论文阅读资料仍保留，方便继续精读。
“收藏浏览器论文”和“手动添加”可以只收藏标题与链接，不下载 PDF，也不调用模型。不扫描浏览器历史。
自动标签采用本机关键词提取，摘要摘自已有中文导读，可能需要修正。编辑标题、标签和摘要后点击“保存卡片”；后续自动同步会保留你的编辑。
在“关联图谱”中，尚未分析时显示共享标签。点击“分析这篇的关联”可生成有类型和双边证据的内容关联；点击论文节点查看卡片。
可将卡片移到“已归档”，勾选“查看已归档”后恢复；原阅读记录不受影响。也可以导出 Markdown 索引。
索引位置：~/Library/Application Support/学术助手/PaperIndex/index.json，仅在本机保存，不会发布到项目仓库。

问以前读过的论文
1. 点击“论文索引”→“问论文库”，描述你记得的内容，例如“之前哪篇用相机测接触力？”；回车或点“发送”。
2. 助手先检查所有未归档论文卡片，再查最多 7 篇候选已有导读和笔记。点击回答中的论文名称回到卡片，展开“查看依据”检查来源。
3. 可继续问“它怎么做实验？”或“这几篇方法有什么区别？”。点击“新对话”切换话题；卡片上的“问这篇”仅针对该论文。
4. 点击“关联图谱”→“分析这篇的关联”，可整理研究问题相近、方法相似、方法差异、结果对照。问答中生成的关系也会保存。每条关系都保留两篇论文各自的短证据。
5. 内容关联是 AI 归纳，不是引用或因果关系。摘要、导读、笔记修改后，旧关系会失效，重新分析即可更新。资料不足时不强行关联。
6. 找回论文依赖标题、标签和摘要；只有标题可能找不到具体方法。回答依据已有导读与笔记，最多每篇 20,000 字符相关节选，不读取 PDF 全文或图片。原文核查可从卡片点“继续精读”。
7. 提问/分析时向 DeepSeek 发送卡片，以及选中的导读和笔记；不发送卡片中的来源链接或本地路径。API 按用量计费。对话仅保留到退出应用，不额外保存；关系及短证据保存在本机 PaperIndex/relations.json，不额外存 PDF，也不上传 GitHub。

论文阅读（中文）

快速看懂一篇论文
1. 打开学术助手，保持它在运行。
2. 在浏览器打开论文 PDF，按 Control + Option + Command + R（⌃⌥⌘R）。
   也可点击“论文阅读”→“链接”，或“导入 PDF”。支持公开 PDF 和 arXiv 链接；有 citation_pdf_url 信息的出版商页面也可识别。
3. 导入完成后点击“生成中文导读”。首次处理需等待，窗口下方会显示状态，可随时取消。
4. 左侧保留原 PDF，右侧导读包含：
   • main idea、论文身份与版本
   • 主要问题、研究缺口
   • related works 的方法路线、瓶颈与本文差异
   • research challenges 与 contributions 的对应关系
   • 方法、关键公式、实验设计
   • 实验如何验证贡献、定量结果与基线比较
   • 局限与建议精读位置
   Related works 只依据本篇论文讨论与引用，保留原文引用编号/作者年份；不会假装读过被引论文，也不会自动联网扩展文献。
5. 点击回答中的 [p. N] 可跳到左侧对应 PDF 页。范围页码跳到起始页。这里使用从 1 起的 PDF 物理页码，可能与期刊印刷页码不同。

细读与连续问答
1. 在浏览器选中一段文字，按 ⌃⌥⌘D。
2. 已导入且来源地址或文字匹配的论文，会自动关联全文；否则明确标为“仅选中段落”，不会混用上一篇论文。
3. 在“细读问答”里输入问题，按 Command + Return（⌘↩）发送；也可点击“解释这段 / 推导公式 / 实验说明什么 / 结论有何局限”。快捷按钮会直接发送所显示类型的问题。
4. 可以继续追问；每次带入当前论文、导读和最近 16 轮问答。全部历史仍保存在本机并可导出。
5. 在助手左侧 PDF 中也能拖选文字，然后点击“用选中段落提问”。不能选字的扫描页，可直接问“请解释第 4 页图 2”。
6. 需要换话题时点“清除引用”，避免沿用上一段。公式在回答中可能以 LaTeX 文本显示，可同时对照左侧原文。

整理与保存
• “我的论文”下拉菜单可切换已读论文，各篇导读、对话和笔记分开保存。
• “重命名”可给论文起一个好找的名称，不改变 PDF 原文。
• “我的笔记”自动保存；“导出笔记”可保存 Markdown 文件，包含导读、手写笔记和完整问答。
• 重复导入同一 PDF 会保留已有笔记和对话。重新生成导读会更新该篇导读。
• 本机资料夹：~/Library/Application Support/学术助手/Papers
• 导入本身仅下载/保存文件。点击生成导读或发送问题时，该篇文字、所选段落、最近问答，以及启用图表选项时的页面图像会发送至 DeepSeek，使用已有 API Key 并产生 API 用量。

图表与读取范围
• 80 页以内默认开启“图表”；长文默认关闭，先提供全文文字。Flash 支持图像，Pro 只读取文字。
• “解读范围”留空为全文；也可填写 20-35 或 5,12-18，使用 PDF 物理页码。开启图表时一次最多 80 页。页面图像和文字都按该范围发送，原始 PDF 仍完整保留。
• 生成部分页面的导读会保存到“细读问答”，保留原有全文导读；每个新回答开头标明本轮文字/图像范围。
• 支持导入 1–1000 页、50 MB 以内 PDF，本机文字保存上限 800 万字符；单次解读最多 200 万字符，超出时保留完整文件并提示选择章节页码。图像体积过大时提示缩小范围，不会悄悄截断正文。
• 长文全文导读耗时和 API 用量更高，可使用页码范围读章节。综述、教程与专著会按材料类型组织导读，不把引用文献的实验当成作者自行开展的实验。
• 需要学校/网站登录的论文，先在已登录浏览器下载，再导入 PDF。助手不复用浏览器登录 Cookie。
• 页码链接方便核对，不保证模型每条结论都准确；重要数字、推导和引用应查看原文。
• 论文阅读规则：~/.codex/skills/summarize-research-paper/SKILL.md；每次请求读取当前版本，文件不可用则使用应用内副本。

窗口布局
点击窗口左上角绿色按钮，或按 Control + Command + F（⌃⌘F）切换全屏。
阅读窗口中间的竖线可以左右拖动，调整原文与导读的宽度；写作窗口也支持拖动分栏，宽度会自动记住。
顶部只保留常用操作，补充说明可将鼠标停在相应按钮或输入框上查看。

快捷键一览
⌃⌘F：切换全屏
⌃⌥⌘P：选文英文润色
⌃⌥⌘R：读取浏览器论文
⌃⌥⌘D：选中段落进入细读问答
⌘↩：发送当前问题或处理写作窗口文本
支持 macOS 服务的应用也可从右键 → 服务 →“学术助手 — 选段问答”进入；浏览器是否显示取决于其文本服务支持。

第一次使用
1. 打开 ~/Applications/学术助手.app。
2. 点击“DeepSeek 设置”。粘贴你自己的 DeepSeek API Key，点击“保存并验证连接”。密钥存入 macOS 钥匙串，普通配置文件中不保存密钥。
   API Key 平台：https://platform.deepseek.com/api_keys
   API 按 DeepSeek 开放平台规则计费；网页登录与 API Key 是不同的接入方式。
3. 点击“启用选文快捷键”，按提示进入系统设置 → 隐私与安全性 → 辅助功能，为“学术助手”打开开关。这是读取所选文字或模拟一次复制所需的系统权限。你需要自己开启。

如果反复出现钥匙串密码提示
确认提示中的应用是“学术助手”，要访问的项目是它自己的 DeepSeek API Key，再输入 Mac 登录密码并选择“始终允许”。普通“允许”只批准这一次访问。
也可在“钥匙串访问”中搜索“学术助手 · DeepSeek API Key”，打开“学术助手 · DeepSeek API Key” →“访问控制”，将 ~/Applications/学术助手.app 加入始终允许的应用列表并保存。保留其他应用访问时需要确认的设置。
更新程序或钥匙串被锁定后，macOS 可能再次要求确认一次；不需要重新填写 DeepSeek API Key。请只在系统弹窗中输入 Mac 密码，不要填进助手的 API Key 输入框。

日常润色
1. 在 Overleaf 的编辑区或浏览器 PDF 中，选中一段文字。
2. 按 Control + Option + Command + P，也就是 ⌃⌥⌘P，然后松开按键。
3. 学术助手读取选文并开始润色，左边保留原文，右边显示结果。
4. 看过预览后点击“复制结果”。返回 Overleaf，确认要替换的原文仍选中后按 Command + V。

读论文与翻译
复制一段文字，点击助手里的“粘贴文字”，选择“中文解释”或“中英翻译”，再点击处理按钮。
中英翻译会识别原文的主要语言：英文译为中文，中文译为学术英文。翻译同样遵循你的学术写作规范，保留技术含义、确定性、数字、公式和引用键。
写作窗口的“中文解释”仅依据当前输入。要读整篇，请进入“论文阅读”。

不授权辅助功能也能使用
先在浏览器里按 Command + C，再打开助手点击“粘贴文字”，然后处理。
支持 macOS 文本服务的应用，还可使用右键 → 服务 → 学术助手 — 英文润色。该入口是否出现取决于当前应用和所选内容。

Overleaf 与 PDF
程序保留原文，不自动把生成结果写回浏览器。
润色指令要求保留 LaTeX 命令、公式、引用键、数量和单位。润色和翻译都会检查 LaTeX 命令、公式和引用是否变化；检测到变化时会显示提示并暂停复制。检查不等于 LaTeX 编译验证，也不能检查所有语义变化，请预览后使用。
扫描件若无法选中文字，可导入“论文阅读”，选择 DeepSeek Flash 并开启“图表”。
建议一次选择一到几段，最多 18,000 个字符。写作窗口处理选文；完整 PDF 与图表由“论文阅读”处理。

后台与退出
关闭窗口后，助手仍在菜单栏运行。点击菜单栏的文字图标可重新打开。
按 Command + Q 或选择菜单栏“退出”会关闭助手，全局快捷键随之停止。
下次使用时重新打开“学术助手.app”。没有设置开机自启动。

快捷键没有反应
先确认“学术助手”仍在运行；第一次开启辅助功能后，可退出助手并重新打开。
必须在目标浏览器窗口中选中文字，然后按 ⌃⌥⌘P。按下后先等待助手弹出，再切换窗口。

连接问题
401/403：检查 API Key 和账号权限。
402：在 DeepSeek 开放平台检查 API 余额。
429：稍后重试。
网络超时：检查网络，或缩短所选段落。
模型默认为 deepseek-flash，也可在设置中选择 deepseek-v4-pro。使用非思考模式执行短文本任务。

数据
处理内容仅在你主动发起时发送至 https://api.deepseek.com。
写作窗口不保存正文历史。论文阅读会将导入 PDF、文字、导读、笔记和问答保存在本机资料夹，便于下次继续；不会把密钥写入这些文件或普通日志。DeepSeek 对 API 数据的处理遵循其平台政策。
如果浏览器不能通过辅助功能直接提供选文，助手会执行一次复制并恢复原有剪贴板；点击“复制结果”才将结果放入剪贴板。
