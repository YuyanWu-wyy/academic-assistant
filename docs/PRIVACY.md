# 数据与隐私

学术助手直接从用户的 Mac 调用 DeepSeek，没有项目自己的中转服务器、遥测或账号系统。

| 数据 | 保存与发送方式 |
| --- | --- |
| DeepSeek API Key | 保存在 macOS 钥匙串；请求时通过 Authorization 请求头发往固定的 DeepSeek API 地址 |
| 写作原文与结果 | 写作窗口不保存历史；发起润色、翻译或解释时发送当前输入与对应写作规则 |
| 论文 PDF 与提取文字 | 导入后保存在本机资料夹；发起导读或问答时发送选定页码的提取文字 |
| 页面图像 | 在启用“同时读取图表”且选择支持图像的模型时发送本轮页面图像 |
| 导读与问答 | 按论文保存在本机；问答请求包含已有导读与最近 16 轮对话 |
| 我的笔记 | 自动保存在本机；当前实现不把手写笔记加入模型请求 |
| 论文来源 URL | 保存在本机阅读记录中，并包含在导出笔记中；导入链接时向对应站点请求 PDF/页面 |
| 浏览器状态 | 通过辅助功能读取活动窗口的来源地址或选中文字；不读取浏览器登录 Cookie |

本机论文目录：`~/Library/Application Support/学术助手/Papers`。阅读记录包括原始文件、来源 URL、文字和用户笔记，可能包含敏感研究内容；不要把这个目录提交到代码仓库。导出的笔记也请在分享前检查。

模型请求目的地固定为 `https://api.deepseek.com`。DeepSeek 的留存、处理和计费规则由其平台决定，本项目不作额外承诺。

辅助功能权限用于全局选文和浏览器地址识别。直接读取选文不可用时，应用会模拟一次复制并尝试恢复原剪贴板。可不授予此权限，改用手动复制粘贴或导入 PDF。

系统询问钥匙串访问时，确认访问方是自己安装的学术助手、项目是它的 DeepSeek API Key 后，可选择“始终允许”。更新本地签名的构建可能使系统再次要求授权。不要为了避免提示而允许所有应用访问密钥。

撤销辅助功能权限后，全局选文会失效。移除应用不会自动删除钥匙串条目或论文资料。请先导出需要的笔记，再自行管理系统钥匙串和本机资料。
