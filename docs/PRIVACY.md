# 数据与隐私

学术助手直接从用户的 Mac 调用所选模型服务，没有项目自己的中转服务器、遥测或账号系统。

| 数据 | 保存与发送方式 |
| --- | --- |
| DeepSeek API Key | 保存在 macOS 钥匙串；请求时通过 Authorization 请求头发往固定的 DeepSeek API 地址 |
| 写作原文与结果 | 写作窗口不保存历史；发起润色、翻译或解释时发送当前输入与对应写作规则 |
| 论文 PDF 与提取文字 | 导入后保存在本机资料夹；发起导读或问答时发送选定页码的提取文字 |
| 页面图像 | 在启用“图表”且选择支持图像的模型时发送本轮页面图像 |
| 导读与问答 | 按论文保存在本机；问答请求包含已有导读与最近 16 轮对话 |
| 我的笔记 | 自动保存在本机；论文库问答会发送候选论文的相关笔记，单篇阅读问答不自动加入手写笔记 |
| 论文索引卡片 | 本机保存标题、链接、主题、简短摘要、记录标识与时间；不复制 PDF、全文、阅读笔记或问答。自动收录和关键词筛选不调用模型；“问论文库”在本机检索，仅将选中的有限材料用于回答 |
| 内容关联 | 保存在本机 relations.json；由主动提问或分析关系生成，修改底层资料后旧关系失效 |
| 论文来源 URL | 保存在本机阅读记录中，并包含在导出笔记中；导入链接时向对应站点请求 PDF/页面 |
| 浏览器状态 | 通过辅助功能读取活动窗口的来源地址或选中文字；不读取浏览器登录 Cookie |

本机论文目录：`~/Library/Application Support/学术助手/Papers`。阅读记录包括原始文件、来源 URL、文字和用户笔记，可能包含敏感研究内容；不要把这个目录提交到代码仓库。导出的笔记也请在分享前检查。

轻量索引目录：`~/Library/Application Support/学术助手/PaperIndex`。它与精读资料分开，保存轻量卡片，以及内容关系的类型、简短说明和双边短证据。自动收录的范围是通过助手导入或打开的论文，不扫描浏览器历史。“收藏浏览器论文”只读取用户主动指定的浏览器页面标题与地址，不下载 PDF。“按标题找原文”会在用户点击后把标题作为 Google Scholar 搜索词打开。

DeepSeek 模式请求发往 `https://api.deepseek.com`。订阅模式把本轮文字经标准输入交给本机官方 Codex，后者发送给 OpenAI；本应用不打开、复制或代理登录凭据。两家服务的留存、处理和额度规则由各自平台决定。

辅助功能权限用于全局选文和浏览器地址识别。直接读取选文不可用时，应用会模拟一次复制并尝试恢复原剪贴板。可不授予此权限，改用手动复制粘贴或导入 PDF。

系统询问钥匙串访问时，确认访问方是自己安装的学术助手、项目是它的 DeepSeek API Key 后，可选择“始终允许”。更新本地签名的构建可能使系统再次要求授权。不要为了避免提示而允许所有应用访问密钥。

撤销辅助功能权限后，全局选文会失效。移除应用不会自动删除钥匙串条目或论文资料。请先导出需要的笔记，再自行管理系统钥匙串和本机资料。

## Library Q&A and content relations

Library retrieval stays on the Mac. Local search and viewing stored graphs make no network requests. A user-triggered model answer sends only selected card/overview/note excerpts: at most 3 × 2,000 characters by default, or 6 × 5,000 characters in explicit detailed mode, plus rules, the question and up to 2,000 characters of recent conversation context. It makes at most one model invocation, without automatic paid retries. No-match queries do not read the API key or call the model. PDF text/images and card source URLs/local paths are omitted; selected note text is included.

Copy/export creates a bounded Markdown context locally without an API call. It contains selected materials, the question, conversation clues and source labels. Copy writes to the system clipboard; export writes only where the user chooses. Copy/export itself sends nothing to Claude Code, Codex, ChatGPT or another tool. Users choose whether to paste or attach the materials there.

Content relations are AI interpretations. Each saved relation contains its type, short explanation, two short supporting quotes, paper/excerpt identifiers and hashes of the underlying card/overview/notes. They live in the local `PaperIndex/relations.json` file (owner read/write only); changed or archived sources are excluded from the displayed graph. Questions and answers are held in memory for the current app session. No additional PDF copies, embeddings, or cloud library are created. Evidence quotes are copied locally from the model-selected source paragraph identifiers, not generated by the model. This establishes provenance, not scientific truth or logical entailment.

## 订阅模式

当前选择应用于写作、导读、单篇问答、论文库问答和关系分析。订阅模式先检查官方 CLI 的登录方式，拒绝 API Key 登录；不读取本应用的 DeepSeek 钥匙串。子进程不继承 API Key、端点覆盖或父聊天标识；不读取用户项目配置，工作目录为临时空目录。文字经标准输入传入，不放进命令参数；临时目录仅包含输出格式文件，请求结束删除。使用只读模式，禁用命令、浏览器、应用连接及多代理工具，临时会话不持久化为可恢复聊天。官方 CLI 自身可能记录运行诊断，受其设置和政策管理；不承诺电脑或服务端完全不留记录。

本应用不自动切换服务、不在失败后重新提交模型请求。官方客户端自身可能重试网络传输；取消或超时无法保证撤销已经发生的订阅用量。检查登录不发起推理；真正回答会使用 Codex 订阅额度。文字上限不等于精确 token 上限，CLI 自身还会添加固定指令。
